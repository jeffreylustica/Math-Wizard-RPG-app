# Math Wizard RPG

This is a browser-based role-playing game where you must solve math problems to defeat enemies and progress through the game.

## Key Learnings & Features:
* Practiced object-oriented programming concepts by organizing game logic with objects and methods.
* Strengthened JavaScript fundamentals including DOM manipulation, event handling, and conditional logic.
* Focused on designing a fun and educational experience that blends math skills with interactive gameplay.
* Deployed using GitHub Pages for easy access and sharing.

Try it out: https://jeffreylustica.github.io/Math-Wizard-RPG-app/
